# 语义参与判断与运行时约束分开

Status: accepted

2026-10-10，用户要求完善决策框架，使主动回复更智能，同时保留此前的低打扰和事实依据要求。Decision 在原有同一次调用里输出发言对象、意图、对话延续、帮助程度、新颖性、把握程度和消息依据；Runtime 核对依据是否真的出现在输入中、回复归属、任务请求以及实际发言频率，再决定最终动作和回复方式。分类等级是模型判断，不是校准过的概率。

本决定修订上一轮基于“问号/问句关键词＋固定 120 秒”的普通群聊放行规则。采用语义判断可识别“用 Python 吧”这样的承接和没有问号的求助，但会带来模型误分类，因此保留来源核对、收尾不接、低把握不主动插话、重复内容不主动回应等约束，并让冷却随群聊繁忙程度和 Bot 发言量在 60/120/300 秒间变化。任务/技能的明确请求检查继续独立执行，不把参与判断当作执行授权。

V7 为成功发送的 Bot 消息保存本地回复锚点，区别于 QQ 协议引用号。对话承接只使用同群、同一人的近期回复关联，旧消息不猜测回填。Trace 同时保留模型建议动作、最终动作和 Runtime 限制原因，以便通过固定场景评测改进；不自动改写人格、训练模型或从一次互动推断长期偏好。没有新评估字段的旧响应走保守兼容路径。
