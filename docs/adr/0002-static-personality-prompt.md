# 人格提示词静态化：仅管理员可改，版本化可回滚

Status: accepted

人格（人设提示词）设定为静态文本：不随对话或归纳流程自动演化，仅管理员可通过 WebUI 人格编辑器修改；每次修改强制版本化，保留 diff 与回滚能力。"像一个人"所需的长期变化，改由记忆与关系承载——人格本身不变，行为随记忆与关系演化（言行因此因人而异、随经历而不同，但"它是谁"始终稳定）。

## Considered Options

- 数值化人格 schema（主动度/幽默度等 0-1 随事件漂移）：表现力薄，且漂移方向不可解释，放弃。
- 由夜间归纳自动改写人设：人格可能滑向不可预期方向，且与"人格可信、可审计"冲突，放弃。

## Consequences

- 人格演化诉求全部转化为记忆/关系/情绪系统的设计压力（见 ADR-0004）。
- 人格误改可回滚，版本历史即审计链；管理员手改也走同一版本通道，无特殊路径。
