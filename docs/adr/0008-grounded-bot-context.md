# 回复采用人物简档、话题记忆和固定对话快照

Status: accepted

2026-10-10，用户确认“回复对象的稳定人物总结＋当前话题相关记忆＋近期对话”，并要求实现及同步文档。本决定修订 Q26/Q27 与架构十二章的 Bot Context 配方；保留 ADR-0007 的回复锚点和按 person_id 跨群归并个人资料的约束。

人物简档由带本人原话出处的少量字段组成，只在获得新的有效资料时更新，不在每轮对旧摘要重新生成摘要。每日摘要保留为历史索引，不自动提升为稳定人物事实。话题记忆按当前问题及引用内容检索当前对象/当前会话的资料，附来源、时间和缺失标记；首版使用本地关键词匹配，接受其无法理解全部同义表达的限制，避免每轮增加模型调用或外部向量服务。

每个聊天窗口保留消息上界，开始处理时在数据库读事务中建立回复快照；Decision 与 bot_chat 共享这份证据，模型等待期间不重新读取近期对话。消息始终携带身份、时间与引用关系，外部消息编号和本地消息编号分别保存；缺失或歧义引用不得猜测映射。快照在内存中只存在于本次处理，不引入跨轮可变聊天 session。

本次消息及其引用作为必要内容优先保留；人物资料和检索记忆可按预算删减，超长原文明确标记截断。预算连必要信息都容纳不了时停止模型调用并记录错误。历史资料与当前明确陈述冲突时提示核对，Bot 自己的旧回答不构成事实证明。此机制降低串人、串话与记忆误用，不能保证模型回答无幻觉。

模型生成的资料仍是提炼结果：运行时验证出处存在、作者正确、引文匹配，不把这种验证解释成对语义真实性的证明。旧无出处记忆保留并标注，不伪造来源，不自动生成可信人物简档。验证边界见[Bot 上下文实现参考](../reference/bot-context.md)。
